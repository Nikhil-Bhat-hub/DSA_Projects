    How the approach works

    Unsorted list: scan every waiting task and choose the highest priority.

    FIFO tie-breaking

    If two tasks have the same priority, the one that arrived first runs first. Example: T5 and T6 both have priority 5, so T5 is selected before T6.

    Priority key

    Priority 10 = urgent; priority 1 = low. The visualizer uses the same scheduling rule for all three data structures, so the selected task should be the same.

    Time-complexity comparison

    ApproachInsertFind nextRemove nextCore idea
